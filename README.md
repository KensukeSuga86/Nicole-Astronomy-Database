# Nicole Astronomy Database

Nicole the Astronavigator / Nicole the Astrorium 共通天文データベースの GitHub Pages 配信用ルートです。

- 最新版: `latest.json`
- v0.1.0: `versions/0.1.0/`
- v0.1.1: `versions/0.1.1/`

v0.1.1 では恒星の B−V・スペクトル型・表示用星色、Deep Sky の所属星座、Messier M1〜M110、アステリズム定義を補完しています。

Nicole 1 / Nicole 2 の本番版では、動作確認した特定バージョンを固定参照する方針です。
