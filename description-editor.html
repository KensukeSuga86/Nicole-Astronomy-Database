Nicole 0 Editor — 使い方

Nicole Astronomy Database の共通解説を、安全に編集・バックアップ・Nicole 2へ反映するための操作ガイドです。

1. 基本の編集手順

  1. 左側で「星座 / 恒星 / 深宇宙天体 / 惑星」を選びます。
  2. 名称またはIDで検索し、編集したい天体を選択します。
  3. 解説欄を書き換えます。
  4. 「この解説を保存」を押します。自動保存をONにしている場合は入力後に自動保存されます。
  5. 「DB原文」と「現在の編集内容」で差を確認します。

2. 編集済みの確認

  • 左側の「編集済みのみ」で、変更済みの天体だけを表示できます。
  • ヘッダーと左側に編集件数が表示されます。
  • 「保存済み / 未保存」表示で、現在の入力がまだ保存されていないか確認できます。
  • 「← 前へ」「次へ →」で同じ種類の天体を順番に確認できます。

3. 保存場所

通常のSafariで開いた場合、編集差分はブラウザの localStorage に保存されます。

Nicole 0の元JSONそのものを書き換えるのではなく、差分だけを別保存します。そのため「この天体だけ初期値へ戻す」や「全編集を消去」で元のDB内容へ戻せます。

4. iPhone / iPadでWebアプリとして使う場合

ホーム画面へ追加したWebアプリは、Safari本体とは別の保存領域として扱われる場合があります。

Nicole 2へ確実に渡したい場合は「編集差分を書き出し」でJSONを保存し、必要な環境で「差分を読み込み」を使ってください。

5. バックアップ

  • 編集差分を書き出し：変更した天体だけをまとめた小さなJSON。
  • この種類の編集済みJSONを書き出す：選択中の種類について、差分を反映した完成JSON。

長時間編集する前後には「編集差分を書き出し」でバックアップしておくのがおすすめです。

6. 差分JSONを読み込む

「差分を読み込み」から、以前書き出したNicole 0 Editorの差分JSONを選択します。読み込むと現在のローカル編集内容が、その差分JSONの内容へ置き換わります。

7. 初期値へ戻す

  • この天体だけ初期値へ戻す：選択中の天体だけ編集を破棄。
  • 全編集を消去：Nicole 0 Editorに保存したすべての差分を消去。
「全編集を消去」は元に戻せません。必要なら先に差分JSONを書き出してください。

8. オフライン利用

Editor本体はPWAとしてキャッシュされます。ただしNicole 0のDB JSONは常に最新版を参照する設計なので、最初の読み込みやDB更新確認にはオンライン接続が必要です。

9. Nicole 2との関係

Nicole 0は共通データベースです。このEditorで保存するのは「Nicole 0の解説差分」で、Nicole 2側が同じ差分を参照できる構成であれば、Nicole 2を再読み込みした際に反映できます。

Webアプリとして独立起動している場合など、保存領域が別れている環境では自動共有されないため、差分JSONの書き出し・読み込みを使って受け渡します。

10. 困ったとき

  • 一覧が出ない → ネットワーク状態とDB読み込みエラー表示を確認。
  • 編集したのに反映されない → 「保存済み」になっているか確認し、Nicole 2側を再読み込み。
  • iPhoneのWebアプリとSafariで内容が違う → 保存領域が別れている可能性があるため、差分JSONで移行。
  • 編集内容を保険として残したい → 「編集差分を書き出し」で定期的にバックアップ。
