# Nicole Astronomy Database v0.4.0

## v0.4.0 — 解説の拡充

- 全278天体（深宇宙天体119・恒星64・星座88・惑星7）の解説を、個々の天体に固有の内容へ書き直しました。
  - 深宇宙天体・恒星・惑星: 「概要」「物語」「天文学的な見どころ」「最新の観測・探査」「観測のポイント」「歴史・名前」
  - 星座: 「天文学」「神話・由来」を拡充し、「観測のポイント」を追加
  - 発見や命名の人間ドラマ、日本の和名・古典（『明月記』『枕草子』など）、JWST・ハッブル・ガイア・イベント・ホライズン・テレスコープなどの最新の観測、ベピコロンボ・JUICE・エウロパ・クリッパー・ドラゴンフライなどの探査計画を、根拠となる文献・発表（`explanation.sources`）とともに収録。
- 新しいフィールド: `explanation.story`（物語）、`explanation.latest`（最新の観測・探査）、`explanation.sources`（根拠）、`explanation.enrichment`（版情報）。`explanation.raw_html` はすべての節から再生成しています（従来のアプリは `raw_html` を優先して表示し、ない場合は従来の4項目で表示します）。
- 解説エディタ: 新しい項目（物語・最新の観測・探査、星座の観測のポイント）を編集可能にし、編集時に `raw_html` を削除せず全節から再生成するよう変更。
- 名称の整理: 「Messier 9」などの仮の名称を「M9 球状星団」などに統一（`catalog.json` も同期）。距離の修正: M12（約1万6,000光年）、M49（約5,600万光年）、IC 434（約1,400光年）。
- 星座線: へび座・へびつかい座を、Sky & Telescope／IAU星図と同じ「星を共有する」線に変更（へび座頭部はへびつかい座δ星へ、尾部はへびつかい座η星から始まりν星を通る）。線分は717→722。新たに使う4星（へび座ι、へびつかい座δ・γ・ν）の座標を埋め込み。へび座・へびつかい座の星座絵の配置を更新。
- ID・スキーマは変更なし。時刻に依存する記述（T CrB の再爆発予測、探査機の到着予定など）は 2026年10月時点の情報です。


## データ所有権・利用先仕様

Nicole Astronomy Database が正本として管理するデータ項目、編集責任、各アプリでの利用箇所、非掌握領域は [DATA-OWNERSHIP.md](./DATA-OWNERSHIP.md) を正式仕様とします。

## v0.3.3 — 解説エディタPWA対応

- `description-editor.html` をホーム画面 / Dock から独立起動できるPWAとして整備。
- `editor.webmanifest` / `editor-sw.js` / `assets/editor/` のPWAアイコンを追加。
- Service Workerの対象は解説エディタのアプリシェルだけに限定し、共通DBの `manifest.json` / `data/*.json` はキャッシュしない。
- DB読込は従来どおり `cache: no-store` を維持し、公開中のNicole 0を正本として参照する。
- オンライン / オフライン状態をエディタ上部に表示。
- WebKitの仕様に合わせ、ホーム画面 / DockのWebアプリはSafariとローカルストレージを共有しないことをUI上で明示。PWAからNicole 2へ編集を渡す場合は差分JSONを書き出して利用する。
- 天文データ本体、ID、スキーマ、`nicole0_description_overrides_v1` はv0.3.2から変更なし。

## v0.3.2 — 共通解説エディタ

- Nicole 0（Nicole Astronomy Database）に `description-editor.html` / `description-editor.js` を追加。
- 星座・恒星・深宇宙天体・惑星の解説をブラウザ上で編集できる。
- 編集内容は `nicole0_description_overrides_v1` としてブラウザのローカル保存領域に保持し、差分JSONとして書き出し・読み込みできる。
- 編集済みのカテゴリJSONも書き出し可能。
- 天文データ本体はv0.3.1と同一で、Aqr星座線ホットフィックスをそのまま維持。

## v0.3.1 — 星座線ホットフィックス

- 2026-10-02のNicole星座編集プロジェクトから、みずがめ座（Aqr）の最終星座線修正を正式反映。
- Aqrの最終線 `HIP112542 → HIP114341` を `HIP112716 → HIP114341` に置換。
- 総セグメント数は717のまま。最終星座線で使用する一意恒星IDは759件（埋込座標269件 + 上流参照490件）。

## v0.3.0 — Nicole標準星座データ正式版

### 座標互換性
標準星座線のトポロジーと星座絵はv0.3.0で正式化され、v0.3.1ではみずがめ座の星座線1箇所のみをホットフィックスしています。
線で使う恒星ID 759件のうち、269件はDB内に座標を保持しています。残る490件のHIP座標は、v0.7.6が従来利用していた `hip_constellation_line_star.csv` を明示的な参照元として保持しています。
これはデータ欠損を推測値で埋めないための互換設計です。将来の完全オフライン版では上流座標カタログをライセンス表示とともに同梱できます。
